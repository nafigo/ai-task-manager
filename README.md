# 🧠 AI Task Manager (Local-First)

A modern, local-first task management application empowered by In-Browser Artificial Intelligence. Built with Next.js and WebLLM.

## ✨ Features

- **Local-First Architecture:** All projects and tasks are stored locally on your device using Dexie.js (IndexedDB). No cloud dependency, ensuring 100% data privacy and offline capability.
- **In-Browser AI Assistant:** Generates autonomous task breakdowns for your projects using the Qwen model via WebGPU. The AI runs directly in your browser without requiring external API calls.
- **Modern UI/UX:** Clean, responsive, and minimalist design built with Tailwind CSS.

## 🚀 Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Database:** Dexie.js (IndexedDB Wrapper)
- **AI Engine:** @mlc-ai/web-llm (Qwen-0.5B / WebGPU)
